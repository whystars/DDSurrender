# DDSurrender
![Exiled](https://img.shields.io/badge/Exiled-9.12.6+-blue)

SCP: Secret Laboratory 服务器的 D级投降 插件，基于 Exiled 框架开发。

## 功能
- 添加.tx投降功能（仅限D级人员，重复投降有彩蛋哦）
- **投降后的D级人员**和混沌**反水**，即**投降D**可以和混沌互相攻击，但是和九尾等MTF阵营视为**友军**，其他逻辑不变
- 投降D逃离后自动转生**九尾收容专家**
- 其他请加上插件体验吧（其实就是介绍完了awa）
- 仅在无友伤服可用（**关闭FriendFire**的情况下，不然你装这个干嘛？）

## 安装
1. 将 `DDSurrender.dll` 放入 `Exiled/Plugins` 目录
2. 配置 `config.yml`：
   请耐心阅读配置文件，本人的插件对于配置文件都进行了详细设计，几乎所有内容都能在配置里面改！！！
